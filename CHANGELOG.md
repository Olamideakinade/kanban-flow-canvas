# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to Semantic Versioning.

## [v1.3.0] - 2025-02-24

### Added
- Advanced search and priority filtering system.
- JSON file import support with file validation and error handling.
- Enhanced keyboard shortcuts (`N`, `/`, `E`, `Escape`).
- Live metrics dashboard tracking completion rates and priority counts.

### Changed
- Complete visual overhaul featuring glassmorphism, refined CSS variables, and modern card styling.
- Upgraded drag-and-drop feedback with active column highlights and smooth transition physics.
- Refactored task management engine into clean modular vanilla JavaScript functions.

### Fixed
- Resolved touch event propagation issues on mobile drag-and-drop handlers.
- Prevented layout thrashing during rapid task filter updates.

## [v1.2.0] - 2025-02-21

### Added
- Initial metrics dashboard showing task totals and completion percentage.
- Export functionality for local task data.

## [v1.1.0] - 2025-02-15

### Added
- Native HTML5 drag-and-drop task migration.
- Local storage synchronization layer.

## [v1.0.0] - 2025-02-10

### Added
- Initial release of Kanban Flow Canvas with core board columns and basic task creation.
