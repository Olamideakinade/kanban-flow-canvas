# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v1.2.0] - 2025-02-21

### Added
- Live metrics dashboard showing total tasks, completion percentage, and urgent item counts.
- JSON file import support alongside robust export functionality.
- Keyboard shortcuts for rapid task creation (`N`), search focus (`(`/`), and export (`E`).
- Smooth visual animations for drag-and-drop interactions and column transitions.
- Task counter badges on column headers.

### Changed
- Overhauled user interface with refined dark mode styling, glassmorphism cards, and improved typography.
- Optimized local storage persistence layer with error boundary protection.

## [v1.1.0] - 2025-02-17

### Added
- Real-time search and filtering capabilities.
- Modal dialog for task creation and editing with validation.

## [v1.0.0] - 2025-02-10

### Added
- Initial release with basic Kanban board columns and drag-and-drop task migration.
